You are the caller. The bank agent "Marina" is generated live: Gemini writes each line from what you just said, ElevenLabs speaks it (browser voice if no key is configured), and Whisper on the server hears you. The agent runs the same verification flow as Altur's: greeting, a question it deliberately interrupts, a folio you must repeat back, a probe about an insurance product that does not exist, a 5-second silence, a last question, a closing. Marina distrusts the caller by default, sees the detector's running score at every turn and uses tactics that trip up an LLM caller; once the call average passes 70% synthetic she adds a challenge step and asks harder questions. Your microphone is streamed at 8 kHz; the verdict updates every 2 seconds. The microphone is checked first (2 s of silence, then a sentence) so you know whether this input could bias the verdict, and the "hearing" line tells you whether the server takes the input as talking, background noise or quiet.

POST /detect (scored endpoint)

Body: JSON with a base64-encoded stereo WAV (any key containing audio, wav, clip, data or file is accepted; raw WAV bytes, a bare base64 body and multipart uploads work too). CORS is open, so any origin can call it.

curl -s -X POST http://127.0.0.1:8000/detect \
  -H "Content-Type: application/json" \
  -d "{\"audio\": \"$(base64 -w0 call.wav)\"}"

{"is_synthetic": true, "confidence": 0.93}

confidence is the probability that the returned verdict is correct (0.5 – 1.0). The raw p_synthetic, per-aspect scores, attack profile, turn timeline and feature vector are returned by POST /analyze (same body; add ?semantic=1 to force the transcript judge).

Other routes

GET /health · GET /samples · POST /analyze?sample=name.wav · WS /ws/live (live call: int16 8 kHz PCM frames in, agent lines and rolling verdicts out) · POST /miccheck (microphone quality report for a short PCM sample) · GET /share (public / LAN links for this server).

Sharing

On the host run share.ps1 (Windows) or share.sh: it opens a public HTTPS tunnel (Cloudflare quick tunnel, no account needed) and the Share link button appears in the header. HTTPS is required for other people's microphones in the live call; the analysis endpoints also work over the plain LAN address.
