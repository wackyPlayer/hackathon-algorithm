You are the caller. The bank agent "Marina" is generated live (Gemini writes each line, ElevenLabs speaks it, Whisper on the server hears you) and runs the three security checks of the brief: the voice itself, the conversation (she interrupts you, falls silent for 5 s and talks over you; people recover instantly and messily, machines consistently) and the semantics (a folio you must repeat back, an insurance product that does not exist; a person says "I don't have that", a language model invents an answer). She distrusts the caller by default, sees the detector's running score every turn, and once the call average passes 70 % synthetic she adds a challenge step and asks harder questions. The microphone is checked first, and the "hearing" line says whether the server takes the input as talking, background noise or quiet.

POST /detect (scored endpoint)

Body: JSON with a base64-encoded stereo WAV (any key containing audio, wav, clip, data or file is accepted; raw WAV bytes, a bare base64 body and multipart uploads work too). CORS is open, so any origin can call it.

curl -s -X POST http://127.0.0.1:8000/detect \
  -H "Content-Type: application/json" \
  -d "{\"audio\": \"$(base64 -w0 call.wav)\"}"

{"is_synthetic": true, "confidence": 0.93}

confidence is the probability that the returned verdict is correct (0.5 – 1.0). The raw p_synthetic, per-aspect scores, attack profile, turn timeline and feature vector are returned by POST /analyze (same body; add ?semantic=1 to run the transcript judge).

Other routes

GET /health · GET /samples · POST /analyze?sample=name.wav · WS /ws/live (live call: int16 8 kHz PCM frames in, agent lines and rolling verdicts out) · POST /miccheck (microphone quality report for a short PCM sample) · GET /share (public / LAN links for this server).

Sharing

On the host run share.ps1 (Windows) or share.sh: it opens a public HTTPS tunnel (Cloudflare quick tunnel, no account needed) and the Share link button appears in the header. HTTPS is required for other people's microphones in the live call; the analysis endpoints also work over the plain LAN address.
